# Use a Rust host, shared Kotlin logic, and native mobile UIs

Remote Agent implements the security-sensitive Host Daemon and Mobile Client transport in Rust. The Host owns one long-lived Codex App Server child process and embeds the `russh` SSH server; Android and iOS connect with per-device SSH public keys over TCP and use the `remote-agent-v3` subsystem. The subsystem carries Codex-native JSONL. The Host inspects only the top-level `method` and `id` needed to classify messages, correlate multiple phones, fan out notifications, and return the first response to a server request; it forwards `params`, `result`, `error`, and unknown fields as raw JSON rather than defining a second typed RPC model. Android and iOS share Kotlin application state, reconciliation, cache rules, and UI projections. Android renders that state with Jetpack Compose and iOS renders it with SwiftUI through one iOS-specific Snapshot/intent interface. Operating-system facilities such as secure storage, QR capture, file picking, lifecycle handling, and SSH connection management remain platform-specific implementations behind Kotlin interfaces. Shell, PTY, exec, and port-forwarding SSH channels are intentionally rejected; only the application subsystem is exposed.
