# Bex と Codex デスクトップアプリの差異リスト

2026-09-11 に Mac 上で両アプリを実際に操作して比較した結果。
対象は Bex.app 0.1.0（このリポジトリの GPUI 版）と ChatGPT.app 26.903（bundle id `com.openai.codex`、Codex モード）。
スクリーンショット撮影と座標クリック、CGEvent によるキー入力で確認した。第 1 章から第 9 章は静的な画面の比較、第 10 章は同じ指示を両方に送って観察した動作の比較。

凡例: **観察** は実際に画面で確認したもの。**文書** は README の記述にもとづくもの。

比較画像は `docs/codex-comparison/` にある。各画像は左が Codex、右が Bex。

## 8. Bex にない Codex の機能

- プルリクエスト画面（レビュー待ち / 過去にレビュー済み / 作成済み）
- スケジュール（予定済みタスクと提案）
- プラグインとスキルのカタログ、インストール済み一覧
- セキュリティ、サイト、カスタマイズの各画面
- アクティビティ表示、未読、ピン留め、アーカイブ、名前変更、分岐、共有、コピー
- 一時チャット、クイックチャット、スタンドアロンチャット、複数ウィンドウ
- 権限モード切替（承認を求める / 代わりに承認 / フルアクセス）
- コンピューター操作（任意のアプリ、Chrome 拡張、Excel）と「Bex を添付」のような画面添付
- ゴール、プランモード、スキルを記録
- テーマとフォントのカスタマイズ、ショートカット再割当
- 使用状況の残量表示、通知ベル、ペット
- フック、接続、Git 設定、環境設定

## 9. Codex にない Bex の機能

- 複数 Host の切替（この端末 / ペアリング済みの他端末）と iroh 経由の接続
- 端末の招待とペアリング、iPhone からの同じ会話の継続
- セッションごとの worktree 自動作成と、指定ファイル（.env など）のコピー
- 会話内の変更サマリーカード（ファイル数と加減行数）
- 右パネルの統合ツールパネル（変更 / ターミナル / サイドチャット / ブラウザ / ファイラ を 1 か所で切替）

## 10. 動作時の比較（同じ指示を両方に送って観察）

両方で remote-agent を選んで新規チャットを作り、同じ文面を送った。Bex は `bex/session-NcOubN` の worktree を作って作業し、Codex は「ローカル」モードでチェックアウトそのものを使った。そのため `ls` の結果が異なり、Codex 側にだけ未追跡の tmp ファイルが並んだ。

## 11. 未検証と補足

- Bex の承認ダイアログ（許可 / このセッションで許可 / 中止）は今回の操作では一度も出なかったため、見た目は未確認。README の記述による。
