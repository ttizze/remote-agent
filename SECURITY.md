# Security / セキュリティ

Only the current unreleased revision is supported. / 対応対象は未リリースの最新リビジョンです。

Report vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/ttizze/remote-agent/security/advisories/new). Include the affected revision, reproduction steps, and impact. Do not post credentials, invitation tickets, or private conversation content in public issues.

脆弱性は [GitHubの非公開報告フォーム](https://github.com/ttizze/remote-agent/security/advisories/new) から、対象リビジョン・再現手順・影響を添えて報告してください。認証情報、招待チケット、非公開の会話内容を公開Issueに投稿しないでください。
